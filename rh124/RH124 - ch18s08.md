## Summary

In this lesson, you learned to manage network settings by using the NetworkManager daemon, and to manage network devices and connections by using the NetworkManager command-line interface (nmcli). RHEL 10 uses an INI-style keyfile format to store network profiles in the /etc/NetworkManager/system-connections directory. Support for the earlier ifcfg file format for network connections is fully removed.\
You can uniquely identify servers with an FQDN, which you can manage by using the hostnamectl command. You also learned to configure and to test local name resolution.\
