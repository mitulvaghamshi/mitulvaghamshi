## Summary

In this lesson, you learned the fundamentals of networking in Red Hat Enterprise Linux, including the TCP/IP model, IP addressing, interface naming, routing, configuration methods, and troubleshooting commands.\
The key protocols for the internet layer are IPv4 and IPv6. An IPv4 address is a 32-bit number shown as four dot-separated octets. An IPv4 address is divided into a network prefix and host identifier by a netmask, and is configurable via DHCP or manually. IPv6 addresses are 128-bit hexadecimal numbers, commonly shown as eight colon-separated hexadecimal groups. IPv6 addresses are often shortened and used with a /64 prefix.\
Red Hat Enterprise Linux uses consistent network interface names that persist across reboots, based on firmware and PCI bus topology, rather than detection order.\
Hosts use a routing table to determine which network interface to use and which router to forward packets to.\
You can use several command-line utilities to gather network information and to troubleshoot issues. For example, you can display address and routing information (the ip command), verify connectivity (the ping and ping6 commands), trace traffic paths (the traceroute, tracepath, and mtr commands), and display socket statistics (the ss and netstat commands).
