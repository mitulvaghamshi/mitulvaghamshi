## Summary

In this lesson, you learned that Linux processes use file descriptors that you can manipulate by using redirection. With redirection, you can save standard output (stdout) or standard error (stderr) to a file, or discard it. You can use redirection operators to send stdout and stderr to the same file or device, or you can send the output to different locations.\
You can connect the stdout of a command to the standard input (stdin) of another command by using pipelines. The purpose of using pipelines is to alter, display, or process output as required.\
You can use redirection and pipelines to process complex command output and to write a large amount of data to files without using a graphical application.
