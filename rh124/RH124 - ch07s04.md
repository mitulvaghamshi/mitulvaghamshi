# Guided Exercise: Create Links Between Files

Create and compare the use of hard links and symbolic links to reference the same file.\
**Outcomes**

- Create hard links and symbolic links between files.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start files-make
```

4. Create the /home/student/links/file.hardlink hard link for the /home/student/files/target.file file. Verify the link count for the original file and the new linked file.
   1. View the link count and the index number (inode) for the /home/student/files/target.file file.The inode number of the file might vary in your environment.[student@servera ~]$ **ls -li files/target.file**
   2. 8838187 -rw-r--r--. 1 student student 11 May 27 13:15 files/target.fileThe link count of the files/target.file is 1 because the file does not have additional links to it.
   3. Create the /home/student/links/file.hardlink hard link. Link it to the /home/student/files/target.file file.[student@servera ~]$ **ln files/target.file links/file.hardlink**
   4. Verify the link count and the inode number for the original file and the new hard link. The link count should be 2 and the inode number must be the same for both files.[student@servera ~]$ **ls -li files/target.file links/file.hardlink**
   5. 8838187 -rw-r--r--. 2 student student 11 May 27 13:15 files/target.file
   6. 8838187 -rw-r--r--. 2 student student 11 May 27 13:15 links/file.hardlinkThe file and the link have the same inode number because they point to the same data.
5. Create the /home/student/tempdir symbolic link that points to the /tmp directory on the servera machine. Verify the newly created symbolic link.
   1. Create the /home/student/tempdir symbolic link to the /tmp directory.[student@servera ~]$ **ln -s /tmp /home/student/tempdir**
   2. Use the ls -l command to verify the newly created symbolic link.[student@servera ~]$ **ls -l /home/student/tempdir**
   3. lrwxrwxrwx. 1 student student 4 May 27 13:53 /home/student/tempdir -> /tmp
