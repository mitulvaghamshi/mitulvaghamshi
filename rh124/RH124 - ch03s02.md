# Guided Exercise: Get Help from Manual Pages

Find information in local Linux system manual pages.\
**Outcomes**\
**Outcomes**

- Search and browse the Linux manual pages to find useful information.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available.

```
student@workstation:~$ lab start help-manual
```
