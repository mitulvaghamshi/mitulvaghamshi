# Guided Exercise: Control System Services

Control system daemons and network services with the systemctl command.\
**Outcomes**

- Use the systemctl command to control systemd services.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start services-control
```
