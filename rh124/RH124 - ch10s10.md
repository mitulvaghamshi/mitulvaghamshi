# Guided Exercise: Manage User Passwords

Set a password management policy for users, and manually lock and unlock user accounts.\
**Outcomes**\
**Outcomes**

- Force a password change when the user logs in to the system for the first time.
- Force a password change every 90 days.
- Set a user account and passwords to expire 180 days from the current day.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available.

```
student@workstation:~$ lab start users-password
```

**Instructions**

1. On the servera machine, lock the operator1 user and try to switch to that user.
   1. As the student user on the workstation machine, log in to the servera machine as the student user.student@workstation:~$ **ssh student@servera**
   2. [student@servera ~]$
   3. As the student user, use administrative rights to lock and expire the operator1 account. Use student as the password.[student@servera ~]$ **sudo usermod -L -e 1 operator1**
   4. [sudo] password for student: **student**
   5. Try to log in as the operator1 user. Use redhat as the password.This command should fail because the operator1 user is locked.[student@servera ~]$ **su - operator1**
   6. Password: **redhat**
   7. su: Authentication failure
   8. Unlock the operator1 account and remove the expiration date.[student@servera ~]$ **sudo usermod -U -e '' operator1**
   9. Try to log in as the operator1 user again. Use redhat as the password. This time, the command should succeed.[student@servera ~]$ **su - operator1**
   10. Password: **redhat**
   11. ...output omitted...
   12. [operator1@servera ~]$
   13. Log out of the operator1 user shell to return to the student user shell.[operator1@servera ~]$ **exit**
   14. logout
2. Change the password policy for the operator1 user to require a new password every 90 days. Confirm that the password age is successfully set.
   1. Switch to the root user. Use student as the password.[student@servera ~]$ **sudo -i**
   2. [sudo] password for student: **student**
   3. [root@servera ~]#
   4. Set the maximum age of the operator1 user's password to 90 days.[root@servera ~]# **chage -M 90 operator1**
   5. Verify that the operator1 user's password expires 90 days after it is changed.[root@servera ~]# **chage -l operator1**
   6. Last password change					: May 14, 2025
   7. Password expires					: Aug 12, 2025
   8. Password inactive					: never
   9. Account expires						: never
   10. Minimum number of days between password change		: 0
   11. Maximum number of days between password change		: 90
   12. Number of days of warning before password expires	: 7
3. Force a password change when the operator1 user logs in for the first time. After configuring the password change, return to the student user's shell.
   1. Force a password change on the first login for the operator1 account.[root@servera ~]# **chage -d 0 operator1**
   2. Exit the root user's shell from the servera machine.[root@servera ~]# **exit**
   3. logout
   4. [student@servera ~]$
4. Log in as the operator1 user and change the password to forsooth123. After setting the password, return to the student user's shell.
   1. Log in as the operator1 user and change the password to forsooth123 when prompted.[student@servera ~]$ **su - operator1**
   2. Password: **redhat**
   3. You are required to change your password immediately (administrator enforced).
   4. Current password: **redhat**
   5. New password: **forsooth123**
   6. Retype new password: **forsooth123**
   7. ...output omitted...
   8. [operator1@servera ~]$
   9. Exit the operator1 user's shell to return to the student user.[operator1@servera ~]$ **exit**
   10. logout
   11. [student@servera ~]$
5. Set the operator1 account to expire 180 days from the current day.
   1. Switch to the root user. Use student as the password.[student@servera ~]$ **sudo -i**
   2. [sudo] password for student: **student**
   3. [root@servera ~]#
   4. Determine the date 180 days in the future. Use the format %F with the date command to get the exact value.[root@servera ~]# **date -d "+180 days" +%F**
   5. 2025-11-10**Important**This returned date is an example; use the value on your system for the following steps.
   6. Set the account to expire on the date that is displayed in the preceding step.[root@servera ~]# **chage -E 2025-11-10 operator1**
   7. Verify that the account expiration date is successfully set.[root@servera ~]# **chage -l operator1**
   8. Last password change : May 14, 2025
   9. Password expires : Aug 12, 2025
   10. Password inactive : never
   11. Account expires : Nov 10, 2025
   12. Minimum number of days between password change : 0
   13. Maximum number of days between password change : 90
   14. Number of days of warning before password expires : 7
6. Set passwords to expire 180 days from the current date for all new users.
   1. In the /etc/login.defs file, set the PASS_MAX_DAYS parameter to 180. Use administrative rights when you open the file with the text editor. You can use the vim /etc/login.defs command to perform this step....output omitted...
   2. # Password aging controls:
   3. #
   4. # PASS_MAX_DAYS Maximum number of days a password may be
   5. # used.
   6. # PASS_MIN_DAYS Minimum number of days allowed between
   7. # password changes.
   8. # PASS_MIN_LEN Minimum acceptable password length.
   9. # PASS_WARN_AGE Number of days warning given before a
   10. # password expires.
   11. #
   12. PASS_MAX_DAYS 180
   13. PASS_MIN_DAYS 0
   14. PASS_MIN_LEN 8
   15. PASS_WARN_AGE 7
   16. ...output omitted...**Important**The default password and account expiration settings apply to new users but not to existing users.
7. Return to the workstation machine as the student user.[root@servera ~]# **exit**
8. logout
9. [student@servera ~]$ **exit**
