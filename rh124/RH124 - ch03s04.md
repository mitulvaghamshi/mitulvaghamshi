## Summary

In this lesson, you learned to use the man command to display information about components of a Linux system, such as files, commands, and functions.\
To refer to a man page, the name of the page is followed by its section number in parentheses. Popular sections include user commands (1), file formats (5), administrative commands (8), and system calls (2).\
You can search for man pages by keyword, and you can navigate a man page by using various key presses and keyboard combinations.
