## Summary

In this lesson, you learned to manage and organize files inside the file-system hierarchy by using the command line.\
To point multiple file names to the same data, you can create hard links and symbolic links.\
You learned to refer to files by using their absolute paths, which start with a forward slash (/), and to refer to files by using their relative paths, which do not start with a forward slash. You can use commands in combination with the dot (.), double dot (..), and tilde (~) special characters to refer to the relative path of a file in the file system.\
You also learned that the Bash shell provides pattern matching, expansion, and substitution features to help you to run commands efficiently.
