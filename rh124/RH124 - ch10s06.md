# Guided Exercise: Manage Local User Accounts

Create, modify, and delete local user accounts.\
**Outcomes**\
**Outcomes**

- Configure a Linux system with additional user accounts.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available.

```
student@workstation:~$ lab start users-user
```

**Instructions**

1. Create the operator1 user on the servera machine, and set the new user's password to redhat.
   1. As the student user on the workstation machine, log in to the servera machine, and switch to the root user. Use student as the password.student@workstation:~$ **ssh student@servera**
   2. ...output omitted...
   3. [student@servera ~]$ **sudo -i**
   4. [sudo] password for student: **student**
   5. [root@servera ~]#
   6. Create the operator1 user and confirm that it exists in the system.[root@servera ~]# **useradd operator1**
   7. [root@servera ~]# **tail /etc/passwd**
   8. ...output omitted...
   9. operator1:x:1003:1003::/home/operator1:/bin/bash
   10. Set the password for the operator1 user to redhat.[root@servera ~]# **passwd operator1**
   11. New password: **redhat**
   12. BAD PASSWORD: The password is shorter than 8 characters
   13. Retype new password: **redhat**
   14. passwd: password updated successfully
2. Create two additional users: operator2 and operator3. Set their passwords to redhat.
   1. Add the operator2 user. Set the password for the operator2 user to redhat.[root@servera ~]# **useradd operator2**
   2. [root@servera ~]# **passwd operator2**
   3. New password: **redhat**
   4. BAD PASSWORD: The password is shorter than 8 characters
   5. Retype new password: **redhat**
   6. passwd: password updated successfully
   7. Add the operator3 user. Set the password for the operator3 user to redhat.[root@servera ~]# **useradd operator3**
   8. [root@servera ~]# **passwd operator3**
   9. New password: **redhat**
   10. BAD PASSWORD: The password is shorter than 8 characters
   11. Retype new password: **redhat**
   12. passwd: password updated successfully
3. Update the operator1 and operator2 user accounts to include the Operator One and Operator Two comments, respectively. Verify that the comments exist for the user accounts.
   1. Run the usermod -c command to update the comments of the operator1 user account.[root@servera ~]# **usermod -c "Operator One" operator1**
   2. Run the usermod -c command to update the comments of the operator2 user account.[root@servera ~]# **usermod -c "Operator Two" operator2**
   3. View the /etc/passwd file to confirm that the comments for the operator1 and operator2 users exist.[root@servera ~]# **tail /etc/passwd**
   4. ...output omitted...
   5. operator1:x:1003:1003:`Operator One`:/home/operator1:/bin/bash
   6. operator2:x:1004:1004:`Operator Two`:/home/operator2:/bin/bash
   7. operator3:x:1005:1005::/home/operator3:/bin/bash
4. Delete the operator3 user along with the user's personal data. Confirm that the operator3 does not exist.
   1. Remove the operator3 user from the system.[root@servera ~]# **userdel -r operator3**
   2. Confirm that the operator3 user does not exist.[root@servera ~]# **tail /etc/passwd**
   3. ...output omitted...
   4. operator1:x:1003:1003:Operator One:/home/operator1:/bin/bash
   5. operator2:x:1004:1004:Operator Two:/home/operator2:/bin/bashNotice that the preceding output does not display the user account information for the operator3 user.
   6. Confirm that the operator3 user home directory does not exist.[root@servera ~]# **ls -l /home**
   7. total 0
   8. drwx------. 3 cloud-user cloud-user 74 May 9 17:17 cloud-user
   9. drwx------. 4 devops devops 90 Mar 6 16:24 devops
   10. drwx------. 2 operator1 operator1 62 May 9 22:35 operator1
   11. drwx------. 2 operator2 operator2 62 May 9 22:35 operator2
   12. drwx------. 3 student student 74 Mar 6 16:23 student
   13. Exit the root user's shell to return to the student user's shell.[root@servera ~]# **exit**
   14. logout
   15. [student@servera ~]$
   16. Return to the workstation machine as the student user.[student@servera ~]$ **exit**
   17. logout
   18. Connection to servera closed.
   19. student@workstation:~$
