## Guided Exercise: Locate Files on a File System

Search for files on a file system that is currently mounted.\
**Outcomes**

- Search for files with the find and locate commands.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start fs-locate
```

**Instructions**

1. Log in to the servera machine as the student user.student@workstation:~$ **ssh student@servera**
2. ...output omitted...
3. [student@servera ~]$
4. Use the locate command to search for the following files on the servera machine.
   1. Update the locatedb database manually on the servera machine.Use the sudo updatedb command to update the database. Use student as the password.[student@servera ~]$ **sudo updatedb**
   2. [sudo] password for student: student
   3. [student@servera ~]$
   4. Locate the logrotate.conf configuration file.[student@servera ~]$ **locate logrotate.conf**
   5. /etc/logrotate.conf
   6. /usr/share/man/man5/logrotate.conf.5.gz
   7. Locate the networkmanager.conf configuration file, ignoring case sensitivity.[student@servera ~]$ **locate -i networkmanager.conf**
   8. /etc/NetworkManager/NetworkManager.conf
   9. /etc/dbus-1/system.d/org.freedesktop.NetworkManager.conf
   10. /usr/share/man/man5/NetworkManager.conf.5.gz
5. Use the find command to search for the following files in real time on the servera machine.
   1. Use root privilege to find all files in the /var/lib directory that the chrony user owns. If required, use student as the Sudo password.[student@servera ~]$ **sudo find /var/lib -user chrony**
   2. /var/lib/chrony
   3. /var/lib/chrony/drift
   4. Use root privilege to find all files in the /var directory that are owned by the root user and the mail group. Use student as the Sudo password.[student@servera ~]$ **sudo find /var -user root -group mail**
   5. /var/spool/mail
   6. Find all files in the /usr/bin directory with a file size greater than 50 KB.[student@servera ~]$ **find /usr/bin -size +50k**
   7. /usr/bin/iconv
   8. /usr/bin/locale
   9. /usr/bin/localedef
   10. /usr/bin/cmp
   11. ...output omitted...
   12. Find all files in the /home/student directory that changed in the last 120 minutes.**Important**Your command output might differ, depending on which files have been modified in the last 120 minutes in your lab environment.[student@servera ~]$ **find /home/student -mmin -120**
   13. /home/student/.bash_logout
   14. /home/student/.bash_profile
   15. /home/student/.bashrc
   16. ...output omitted...
   17. Find all block device files in the /dev directory.[student@servera ~]$ **find /dev -type b**
