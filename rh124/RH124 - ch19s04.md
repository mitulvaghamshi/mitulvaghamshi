## Guided Exercise: Configure SSH Key-based Authentication

Enable secure remote access for authorized users by configuring key-based authentication.\
**Outcomes**

- Generate an SSH key pair with and without passphrase protection.
- Configure the ssh-agent key manager to use a passphrase-protected key for authentication.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start ssh-keyauth
```
