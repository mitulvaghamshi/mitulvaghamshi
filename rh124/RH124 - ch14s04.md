# Guided Exercise: Mount and Unmount a File System

Mount and unmount a file system that is on removable media.\
**Outcomes**\
**Outcomes**

- Identify and mount a new file system at a specified mount point, and then unmount the file system.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start fs-mount
```

**Instructions**

6. A new partition with a file system is added to the /dev/sdb disk on the servera machine. Mount the newly available partition by using the UUID at the /mnt/part1 mount point.
   1. Create the /mnt/part1 directory.[root@servera ~]# **mkdir /mnt/part1**
   2. Query the UUID of the /dev/sdb1 device.[root@servera ~]# **lsblk -fp /dev/sdb**
   3. NAME FSTYPE ... UUID FSAVAIL FSUSE% MOUNTPOINTS
   4. /dev/sdb

   6. Mount the file system by using the UUID on the /mnt/part1 directory. Use the /dev/sdb1 UUID from the previous command output.[root@servera ~]# *_mount \*_
   7. **UUID="2dfe4a17-d529-480a-a53e-9c28ff49545e" /mnt/part1**
   8. Verify that the /dev/sdb1 device is mounted on the /mnt/part1 directory.[root@servera ~]# **lsblk -fp /dev/sdb**
   9. NAME FSTYPE ... UUID FSAVAIL FSUSE% MOUNTPOINTS
   10. /dev/sdb

7. Change to the /mnt/part1 directory and create the testdir subdirectory. Create the /mnt/part1/testdir/newmount file to verify that you can write to the mount point.
   1. Change to the /mnt/part1 directory.[root@servera ~]# **cd /mnt/part1**
   2. Create the /mnt/part1/testdir directory.[root@servera part1]# **mkdir testdir**
   3. Create the /mnt/part1/testdir/newmount file.[root@servera part1]# **touch testdir/newmount**
8. Unmount the file system that is mounted on the /mnt/part1 directory.
   1. Try to unmount the /mnt/part1 directory with the shell still in the /mnt/part1 directory. The umount command fails to unmount the device.[root@servera part1]# **umount /mnt/part1**
   2. umount: /mnt/part1: target is busy.
   3. Change the shell's current directory to the /root directory.[root@servera part1]# **cd**
   4. [root@servera ~]#
   5. Unmount the /mnt/part1 directory.[root@servera ~]# **umount /mnt/part1**
