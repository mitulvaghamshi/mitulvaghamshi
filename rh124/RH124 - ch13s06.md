## Summary

In this lesson, you learned to configure Flatpak and used it to manage software.\
Flatpak uses remote repositories that store the applications and the required runtimes to execute those applications in an isolated execution environment. The remote repositories enable the automatic resolution of dependencies.\
You can use the command-line interface to install, update, list, remove, and get metadata information about Flatpak applications and runtime dependencies.\
By using the GNOME Software graphical tool, you can install and uninstall Flatpak applications as you would with RPM packages.
