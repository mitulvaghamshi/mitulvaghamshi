## Summary

In this lesson, you learned to manage block storage device, access the contents of a file system on removable media, and search the files on the file system.\
Storage devices are represented by the block device file type. You can use the df command to identify total disk space, used disk space, and free disk space on all mounted regular file systems. You can also list the details of the block devices, such as size and the UUID.\
As a privileged user, you can manually mount and unmount a file system. To successfully unmount a file system, make sure that all processes that access the mount point are stopped. Removable storage devices are mounted in the /run/media directory when using the graphical environment.\
You can search for files in the file system by using indexes or real time searches. The locate command uses indexes to search for files. These indexes use a database that requires frequent updates. The find command performs real time searches in the local file systems. With the find command, you can search based on various file attributes, such as size, location, ownership, and permissions.
