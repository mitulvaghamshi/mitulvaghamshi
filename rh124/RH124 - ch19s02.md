## Guided Exercise: Manage SSH Host Keys

Preconfigure client systems with the SSH host keys of the servers that they use.\
**Outcomes**\
**Outcomes**

- Verify the fingerprints of SSH host keys before logging in to remote hosts.
- Regenerate host key pairs on SSH servers.
- Prepopulate a system-wide known hosts file to help users log in to trusted hosts.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start ssh-hostkeys
```

9. Although the operator1 user account is configured to re-establish trust, a system-wide known hosts file, which an administrator creates with the serverb machine's correct key, would benefit other users on the system. Create the /etc/ssh/ssh_known_hosts file on the servera client, and add the serverb machine's public key to this file.
   1. Use the ssh-keyscan command to retrieve the ED25519 host key of the serverb machine.[student@servera ~]$ **ssh-keyscan -t ed25519 serverb**
   2. # serverb:22 SSH-2.0-OpenSSH_9.9
   3. serverb ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEg3+nm5bXhFDbmYzQx2ov6/XVF2Saf4Xv0VcPO4cVBH
   4. [student@servera ~]$The key might differ in your environment.
   5. Save the key in the system-wide known hosts file to help other users on the servera system to identify trusted hosts. Use student for the Sudo password.[student@servera ~]$ *_sudo bash -c 'ssh-keyscan -t ed25519 \*_
