## Summary

In this lesson, you learned to create, view, and edit text files from the command line. Red Hat recommends learning to edit files with the Vim text editor because it is available in most Linux distributions.\
You can use multiple keystrokes to edit a text file in a command-line text editor. You can use the vimtutor command to learn the core Vim functions.\
You can configure the behavior of the Vim editor for the entire system or for a specific user in the /etc/vimrc and the ~/.vimrc configuration files, respectively.\
