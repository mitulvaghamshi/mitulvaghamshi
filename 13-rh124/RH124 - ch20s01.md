# Summary of Learning Objectives

## Objectives

- After completing this section, you should have reviewed and refreshed the knowledge and skills that you learned in Red Hat System Administration I.

## Reviewing Red Hat System Administration I

Before beginning the comprehensive review for the Red Hat System Administration I course, you should be comfortable with the topics that are covered in each chapter. Do not hesitate to ask the instructor for extra guidance or clarification on these topics.\
**Chapter 1, Introduction to Red Hat Enterprise Linux**\
Define and explain the following concepts: open source, Linux, Linux distributions, and Red Hat Enterprise Linux.

- Define and explain the following concepts: open source, Linux, Linux distributions, and Red Hat Enterprise Linux.\
  **Chapter 2, Accessing the Command Line**\
  Log in to a Linux system and run simple commands by using the shell.
- Log in to a Linux system and run simple commands by using the shell.
- Log in to a Linux system with the GNOME desktop environment and run commands from a shell prompt in a terminal program.
- Save time when running commands from a Bash shell prompt by using some of its productivity features.
- Access the command line on a Linux system and use the Bash shell to run commands.\
  **Chapter 3, Getting Help from Local Documentation**\
  Resolve problems by using information in local help systems and documentation.
- Find information in local Linux system manual pages.
- Get information from local documentation to help you to run commands and to complete tasks.\
  **Chapter 4, Registering Systems for Red Hat Support**\
  Register a system by using your Red Hat account to get support services and software that Red Hat provides.
- Register a system by using your Red Hat account.\
  **Chapter 5. Getting AI-assisted Help with RHEL Lightspeed**\
  Get AI-driven guidance and suggestions to efficiently manage a RHEL server by using Red Hat Enterprise Linux Lightspeed.
- Troubleshoot problems by phrasing effective questions and evaluating the answers that RHEL Lightspeed provides.\
  **Chapter 6. Navigating the File-system Hierarchy**\
  Describe the organization of files in the Linux file-system hierarchy and specify files by name, by using relative paths or absolute paths.
- Describe how Linux files are organized, and the purposes of various directories in the file-system hierarchy.
- Specify the absolute location and relative location of files to the current working directory, determine and change the working directory, and list the contents of directories.\
  **Chapter 7. Managing Files from the Command Line**\
  Copy, move, create, delete, and organize files from the command line.
- Create, copy, move, and remove files and directories.
- Create and compare the use of hard links and symbolic links to reference the same file.
- Efficiently run commands that affect many files by using pattern matching features of the Bash shell.
- Copy, move, create, delete, and organize files from the command line.\
  **Chapter 8. Editing Text Files**\
  Create, view, and edit text files from the command line.
- Create, view, and edit text files from the command line.\
  **Chapter 9. Redirecting Shell Input and Output**\
  Redirect the output of commands and input to commands, by using Bash.
- Save output or errors to a file with shell redirection, and process command output through multiple command-line programs with pipes.\
  **Chapter 10. Managing Local Users and Groups**\
  Obtain superuser access to a system; create, manage, and delete local users and groups; and administer local password policies.
- Describe the purpose of users and groups on a Linux system.
- Switch to the superuser account to manage a Linux system, and grant other users superuser access by using Sudo.
- Create, modify, and delete local user accounts.
- Create, modify, and delete local group accounts.
- Set a password management policy for users, and manually lock and unlock user accounts.
- Obtain superuser access to a system; create, manage, and delete local users and groups; and administer local password policies.\
  **Chapter 11. Controlling Access to Files**\
  Set standard permissions on files and interpret the security effects of different permission settings.
- List file system permissions on files and directories, and interpret how those permissions control access by users and by groups.
- Change the permissions and ownership of files with command-line tools.
- Control the default permissions of user-created files, and explain special permissions on files.
- Set standard permissions on files and interpret the security effects of different permission settings.\
  **Chapter 12. Installing and Updating Software with RPM**\
  Download, install, update, and manage software packages from Red Hat and DNF package repositories.
- Explain how Red Hat and other sources provide software as RPM packages, and investigate the installed system packages.
- Find, install, and update software packages with DNF.
- Enable and disable server use of Red Hat or third-party DNF repositories.\
  **Chapter 13. Installing and Updating Applications by Using Flatpak**\
  Install, upgrade, and use desktop software from the Red Hat Ecosystem Catalog by using Flatpak.
- Install and configure Flatpak tools and access to remote repositories.
- Search for, install, run, update, and remove applications by using Flatpak.\
  **Chapter 14. Accessing Removable Media**\
  Access file systems on removable media devices by mounting them on a directory in the file-system hierarchy.
- Match a block storage device with the file system that a particular directory uses, and determine the amount of free space on that file system.
- Access the contents of a file system on removable media by mounting it into the file-system hierarchy, and unmounting it when you are finished.
- Search for files on a file system that is currently mounted.\
  **Chapter 15. Monitoring and Managing Linux Processes**\
  Investigate, control, and terminate processes that run on a Red Hat Enterprise Linux system.
- Identify the processes that are currently running on a system, determine their current process states, and gather information about their use of system resources.
- Control foreground and background processes on the same terminal by using job control.
- Send signals to processes to control their activity or to terminate execution.
- Interpret and monitor system metrics, and investigate the implications of those measurements to improve your system's performance.\
  **Chapter 16. Controlling Services and Daemons**\
  Control and monitor the system services and daemons that systemd starts.
- List the system daemons and network services that start at boot time as services, or that start and stop dynamically when a network connection is established.
- Control system daemons and network services with the systemctl command.\
  **Chapter 17. Introduction to Networking**\
  Describe basic TCP/IP networking concepts and investigate the current network configuration and functionality on a server.
- Describe the fundamental concepts of network addressing and routing for a server.
- Test and inspect the current network configuration by using command-line utilities.\
  **Chapter 18. Managing Network Configuration**\
  Configure network interfaces and settings on Red Hat Enterprise Linux servers.
- Manage network settings and devices from the command line by using the nmcli command.
- Modify network configuration by editing configuration files.
- Configure a server's static hostname and its name resolution, and test the results.
- Configure network interfaces and settings on Red Hat Enterprise Linux servers.\
  **Chapter 19. Configuring and Securing SSH**\
  Protect SSH communication by managing host keys and by implementing key-based authentication for users.
- Prevent impersonating attacks by configuring the SSH service of client systems to use trusted host keys.
- Configure user accounts to use key-based authentication so that an authorized user can securely log in to a specific account on a remote system without a password.
