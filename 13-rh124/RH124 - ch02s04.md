# Guided Exercise: Access the Command Line with the Desktop Environment

Log in to a Linux system with the GNOME desktop environment and run commands from a shell prompt in a terminal program.\
**Outcomes**

- Log in to a Linux system by using the GNOME desktop environment.
- Run commands from a shell prompt in a terminal program.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available.

```
student@workstation:~$ lab start cli-desktop
```

**Instructions**

1. Log out of the GNOME desktop.
   1. On the workstation machine, click the system menu in the upper-right corner.
   2. Click the Power icon, and then click Log Out.
   3. Click Log Out in the confirmation dialog box.
2. Log in to the workstation machine as the student user with student as the password.
   1. Click the student user account on the GNOME login screen. Enter student when prompted for the password.
   2. Press **Enter**.
3. Use the terminal to change the password for the student user from student to redhat!23.**Important**The lab finish script at the end of this exercise resets the password for the student user to student. You must execute the script at the end of the exercise.
   1. Open a terminal.Press the **Super** key twice to enter the Activities Overview, or click the Red Hat logo in the upper-left corner. Type terminal, and then press **Enter** to open the terminal.
   2. In the terminal window, enter the passwd command at the shell prompt. Follow the prompts in the terminal to change the student user's password from student to redhat!23.student@workstation:~$ **passwd**
   3. Changing password for user student.
   4. Current password: **student**
   5. New password: **redhat!23**
   6. Retype new password: **redhat!23**
   7. passwd: all authentication tokens updated successfully.
4. Log out of the GNOME desktop, and then log back in as the student user with redhat!23 as the password, to verify the changed password.
   1. Click the system menu in the upper-right corner.
   2. Click the Power icon, and then click Log Out.
   3. Click Log Out in the confirmation dialog box.
   4. At the GNOME login screen, click the student user account. Enter redhat!23 when prompted for the password.
   5. Press **Enter**.
5. Lock the screen.
   1. From the system menu in the upper-right corner, press the Lock icon.
6. Unlock the screen.
   1. Press **Enter** to unlock the screen.
   2. In the Password field, enter redhat!23 as the password.
   3. Press **Enter**.
7. Determine how to shut down the workstation machine from the graphical interface, but cancel the operation without shutting down the system.
   1. From the system menu in the upper-right corner, click the Power icon, and then click Power Off. A dialog box is displayed with the options to either Cancel or Power Off the machine.
   2. Click Cancel.
8. Open a terminal and use the following lab command to finish the exercise.
   1. Press the **Super** key twice to enter the Activities Overview, or click the Red Hat logo in the upper-left corner. Type terminal, and then press **Enter** to open the terminal.
