## Summary

In this lesson, you learned that Linux stores all files on file systems, organized into a single inverted tree called the file-system hierarchy.\
Each subdirectory under the root directory (/) is used for different purposes, such as the /boot directory, which contains files used to boot the system, and the /etc directory, which contains system configuration files.\
Files in Linux are case-sensitive and you can refer to files by using its absolute path or its relative path. You can navigate the file system by using the cd command, which accepts paths to directories as parameters, including the special directories named with a single dot (.) for the current working directory, and with a double dot (..) for its parent directory.\
You can list the contents of directories by using the ls command, which by default does not show hidden files. Any file that has a name that starts with a dot (.) is a hidden file.
