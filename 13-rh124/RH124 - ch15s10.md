## Summary

In this lesson, you learned to manage, monitor, and send signals to the processes in the system. A process is a running instance of an executable program. In Linux, processes are assigned to a state, which can be running, sleeping, stopped, or zombie.\
By using job control features, you can manage foreground and background processes on the same terminal. You can also control processes with signals, which is a software interrupt that reports events to an executing program.\
Finally, you can monitor process activity by understanding the system's load average, which is an estimate of how busy the system is.
