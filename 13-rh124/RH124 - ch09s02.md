# Guided Exercise: Redirect Output to Files and Programs

Save output or errors to a file with shell redirection, and process command output through multiple command-line programs with pipes.\
**Outcomes**\
**Outcomes**

- Use redirection to save standard output and standard error to files.
- Use pipelines to send output from one command into another.\
  As the student user on the workstation machine, use the lab command to prepare your environment for this exercise, and to ensure that all required resources are available.

```
student@workstation:~$ lab start shellio-redirect
```
