# Accessing the Command Line with the Desktop Environment

## Objectives

- Log in to a Linux system with the GNOME desktop environment and run commands from a shell prompt in a terminal program.

## The GNOME Desktop Environment

The desktop environment is the graphical user interface on a Linux system. GNOME 47 is the default desktop environment in Red Hat Enterprise Linux 10. GNOME provides an integrated desktop for users and a unified development platform on top of a graphical framework that is powered by Wayland.\
The highly customizable GNOME Shell provides the core user interface functions for the desktop environment. In RHEL 10, the default GNOME Shell appearance is the standard GNOME theme, which is used in this section. You can switch from the default to the GNOME Classic theme, which is closer to the appearance of earlier versions of the GNOME desktop. You can set the theme persistently by clicking the Settings icon at login. The Settings icon displays after selecting the user account, but before entering the password.\
The first time that you log in as a new user, the Tour program starts automatically to provide a quick overview of new RHEL 10 desktop features. The tour is entirely optional and you can close the window to skip it.\

**Keyboard Shortcuts**\
The GNOME Shell enables you to customize keyboard shortcuts for navigating the desktop environment. Open the system menu in the upper-right corner, and click the Settings icon. In the application window that opens, select Keyboard from the left pane. The right pane displays your current shortcut settings in → .\
Some keyboard shortcuts, such as function keys or the **Super** key, might be difficult to send to a virtual machine. Special keystrokes that those shortcuts use might be captured by your local operating system, or by the application that you are using to access the graphical desktop of your virtual machine.

## Important

In some Red Hat training environments, your web browser might not pass the **Super** key to the virtual machine in the classroom environment. To address this issue, you can use an on-screen keyboard.\
At the top of your browser window that displays the interface for your virtual machine, click the keyboard icon on the right side. An on-screen keyboard opens. Click the icon again to close the on-screen keyboard.\
The on-screen keyboard treats the **Super** key as a modifier key that is often held down while pressing another key. If you click it once, then the key turns yellow, to indicate that the key is being held down. So for example, to enter the **Super**+**M** key combination in the on-screen keyboard, click **Super**, and then click **M**.\

**Accessing Workspaces**\
Workspaces are separate desktop screens that display various application windows. You can use workspaces to organize the working environment by grouping open application windows by task. For example, you can group windows for a particular system maintenance activity (such as setting up a new remote server) in one workspace, and then group email and other communication applications in another workspace.\
To switch between workspaces, choose between two methods. The first method is to press **Ctrl**+**Alt**+**LeftArrow** or **Ctrl**+**Alt**+**RightArrow** to switch between workspaces sequentially.\
The second method is to enter the Activities Overview by clicking the Red Hat logo in the upper-left corner, and then clicking the desired workspace.

An advantage of using the Activities Overview to select workspaces is that you can click and drag windows between workspaces. You can view active workspaces by clicking Show Applications in the dash, and the active workspaces display below the search bar.\
Workspaces can be configured as dynamic or fixed. Dynamic Workspaces is the default setting. With dynamic workspaces, you create workspaces by dragging windows from one workspace to another, and empty workspaces are removed. Alternatively, you can set a fixed number of workspaces that will always display, including empty workspaces.\
To configure workspace settings, go to → → . You can select Dynamic Workspaces or Fixed Number of Workspaces.\
**Starting a Terminal**\
In RHEL 10, the Ptyxis terminal emulator replaces the GNOME Terminal. Use one of the following methods to start a terminal:

- From the Activities Overview, select Terminal from the dash, either by clicking its icon in the dash or by using Show Applications.
- Search for terminal in the search field at the top of the windows overview.
- Press the **Alt**+**F2** key combination to open the Run a Command screen, and enter ptyxis to start the terminal.\
  When you open a terminal window, a shell prompt displays for the user who started the graphical terminal program. The shell prompt and the terminal window's title bar indicate the current username, hostname, and working directory.\
  **Locking the Screen and Logging Out**\
  Lock the screen, or log out entirely, by using the system menu in the upper-right corner.\
  To lock the screen, go to the system menu, and click the Lock icon at the right side of the menu, or press **Super**+**L** (which might be easier to remember as **Windows**+**L**). The screen also locks if the graphical session is idle for a few minutes.\
  To lock the screen, go to the system menu, and click the Lock icon at the right side of the menu, or press **Super**+**L** (which might be easier to remember as **Windows**+**L**). The screen also locks if the graphical session is idle for a few minutes.\
  A lock screen curtain appears that shows the system time and the name of the logged-in user. To unlock the screen, you can press **Enter**, press **Space**, or click the left mouse button. Then, enter that user's password on the lock screen.\
  To log out and end the current graphical login session, go to the system menu in the upper-right corner, click the Power icon, and then click Log Out. The confirmation dialog provides the option to cancel or confirm the log out action.\
  **Powering off or Rebooting the System**\
  To shut down the system, go to the system menu in the upper-right corner, click the Power icon, and then click Power Off. Alternatively, press **Ctrl**+**Alt**+**Del**. The confirmation dialog provides the option to cancel or confirm the power off action. If you do not make a choice, then the system automatically shuts down after 60 seconds.\
  To reboot the system, go to the system menu in the upper-right corner, click the Power icon, and then click Restart. The confirmation dialog provides the option to cancel or confirm the restart action. If you do not make a choice, then the system automatically restarts after 60 seconds.\
  In RHEL 10, when rebooting or shutting down, GNOME might give you an option to Install pending software updates if updates are available. You can deselect the checkbox to avoid the update when shutting down or rebooting.
