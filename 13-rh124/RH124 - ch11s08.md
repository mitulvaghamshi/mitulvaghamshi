## Summary

In this lesson, you learned how Red Hat Enterprise Linux manages file ownership and permissions.\
All files belong to an owner and a group. Permission settings determine who can access files (user, group, and others), and what kind of access they have (read, write, and execute). The most specific permissions take precedence: user permissions take precedence over group permissions, and group permissions override others.\
You can view file ownership and permissions by using the long listing format of the ls command.\
You can change file permissions by using either symbolic or octal notation. Additionally, you can recursively change the permissions across directories by using the chmod -R command. The suid, sgid, and sticky special permissions provide additional access-related features to files.\
You also learned to view and define umask values. The default umask values for Bash are defined in the /etc/login.defs file and might be affected by settings in the /etc/profile and /etc/bashrc files, files in /etc/profile.d, or your account's shell initialization files.\
Red Hat Enterprise Linux 9 and later versions consistently apply a default umask of 0022 for all users, in both login and non-login shells.\
