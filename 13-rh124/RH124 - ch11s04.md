# Guided Exercise: Manage File Permissions from the Command Line

Change the permissions and ownership of files with command-line tools.\
**Outcomes**\
**Outcomes**

- Create a directory that all members of a group can access.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start perms-cli
```

**Instructions**\
The lab start command prepares the environment by creating a group named consultants and creating two users, consultant1 and consultant2, who are members of this group.\

   2. ...output omitted...

2. Modify the permissions of the consultants group to allow its group members to create files in, and delete files from, the /home/consultants directory.Also configure the directory to forbid others from accessing the files.
   1. Verify that the permissions of the consultants group allow its group members to create files in, and delete files from, the /home/consultants directory.Note that the consultants group currently does not have write permission.[root@servera ~]# **ls -ld /home/consultants**
   2. drwxr-xr-x. 2 root consultants 6 May 28 21:16 /home/consultants
   3. Add write permission for the consultants group. Use the symbolic method for setting the appropriate permissions.[root@servera ~]# **chmod g+w /home/consultants**
   4. [root@servera ~]# **ls -ld /home/consultants**
   5. drwxrwxr-x. 2 root consultants 6 May 28 21:16 /home/consultantsThe new set of permissions for the consultants group (rwx) includes read, write, and execute.
   6. Forbid others from accessing files in the /home/consultants directory. Use the octal method for setting the appropriate permissions.[root@servera ~]# **chmod 770 /home/consultants**
   7. [root@servera ~]# **ls -ld /home/consultants**
   8. drwxrwx---. 2 root consultants 6 May 28 21:16 /home/consultantsThe new set of permissions for others (---) restricts them from all access to the directory.
