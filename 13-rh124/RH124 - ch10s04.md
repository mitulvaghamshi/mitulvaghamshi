# Guided Exercise: Gain Superuser Access

Switch to the superuser account to manage a Linux system, and grant other users superuser access by using Sudo.\
**Outcomes**\
**Outcomes**

- Use Sudo to switch to the root user, and access the interactive shell as the root user without knowing the password of the superuser.
- Verify the behavior of the su command by switching users directly and by opening a login shell.
- Use Sudo privileges as a regular user to manage a restricted file.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available.

```
student@workstation:~$ lab start users-superuser
```
