## Summary

In this lesson, you learned that the systemd utility provides tools for activating system resources, server daemons, and other processes, both at boot time and on a running system.\
For example, the systemctl command enables and disables services, and can list the status of all daemons that are running in the system. You can manage each daemon by setting its autostart configuration or by starting, stopping, and restarting the daemon.\
The systemd utility also manages service units, socket units, and path units. It can mask a service unit so that it does not run, even to satisfy dependencies.
