Perform the following tasks on the serverb machine:

- Identify the unused, unmounted block device that contains an XFS file system on the serverb machine. Mount the block device on the /review5-disk directory.
- Find the review5-path file. Create the /review5-disk/review5-path.txt file that contains a single line with the absolute path to the review5-path file.
- Find all the files with the 640 octal permissions, and that are owned by the contractor1 user and the contractor group. Save the list of these files in the /review5-disk/review5-perms.txt file.
- Find all files with a size of 100 bytes. Save the absolute paths of these files in the /review5-disk/review5-size.txt file.

1. Log in to the serverb machine as the student user, and switch to the root user.
2. Use the lsblk -fs command to identify the unmounted block device that contains an XFS file system.
3. Create the /review5-disk directory and mount the sdb1 block device on it.[root@serverb ~]# *_mkdir /review5-disk && \*_
4. **mount /dev/sdb1 /review5-disk**
5. Create the /review5-disk/review5-path.txt, /review5-disk/review5-perms.txt, and /review5-disk/review5-size.txt files with the specified content.[root@serverb ~]# *_find / -iname review5-path 2>/dev/null \*_
6. *_> /review5-disk/review5-path.txt ; \*_
7. *_find / -user contractor1 \*_
8. *_-group contractor -perm 640 2>/dev/null \*_
9. *_> /review5-disk/review5-perms.txt ; \*_
10. *_find / -type f -size 100c 2>/dev/null \*_
11. **> /review5-disk/review5-size.txt**
