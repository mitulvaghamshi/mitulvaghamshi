# Lab: Manage Networks

Configure and test network connectivity.\
**Outcomes**

- Configure network settings.
- Test network connectivity.
- Set a static hostname.
- Use locally resolvable canonical hostnames to connect to systems.

## Important

When you adjust network settings, running an incorrect command might lock out your session or cause it to hang, to make your system inaccessible. To avoid locking yourself out of the system, consider adjusting the network configuration through the remote console.\
**Specifications**\
As a system administrator, you are tasked to configure network settings and the hostname on a newly provisioned machine. Completing the network configuration of a server is a prerequisite to delegate the machine to developers and application users to set up and test their applications.\
Perform the following tasks on the serverb machine:

- Find the unused network device and use it to create and activate a static connection profile. Configure the static profile to statically set network settings and not to use DHCP. Use the information from the following table for other connection settings:

| Parameter    | Setting        |
| ------------ | -------------- |
| IPv4 address | 172.25.250.111 |
| Netmask      | 255.255.255.0  |
| Gateway      | 172.25.250.254 |
| DNS Server   | 172.25.250.254 |

- Set the hostname to server-review4.lab4.example.com.
- Set client-review4 as the canonical hostname for the servera 172.25.250.10 IPv4 address.
- Configure the static connection profile with an additional IPv4 address of 172.25.250.211 with a netmask of 255.255.255.0. Do not remove the existing IPv4 address. Ensure that the serverb machine responds to all addresses when the static connection is active.

1. Use the serverb console to log in as the student user on the serverb machine, and switch to the root user.
2. Use the nmcli device status command to determine the unused Ethernet device.**Important**The name of the network interface that is associated with the provided MAC address might vary according to the course platform and hardware in use. This activity assumes that the interface name is ens4.
3. Create a static connection profile, activate the new connection profile, and configure a new hostname.[root@serverb ~]# *_nmcli connection add con-name static type ethernet \*_
4. *_ifname ens4 ipv4.addresses '172.25.250.111/24' ipv4.gateway '172.25.250.254' \*_
5. *_ipv4.dns '172.25.250.254' ipv4.method manual \*_
6. *_&& nmcli connection up static \*_
7. **&& hostnamectl hostname server-review4.lab4.example.com**
8. Update the /etc/hosts file with the client-review4 server name for the 172.25.250.10 IPv4 address.
9. Modify the static connection profile, configure the additional 172.25.250.211/24 IPv4 address, and activate the new IP address.[root@serverb ~]# *_nmcli connection modify static \*_
10. *_+ipv4.addresses '172.25.250.211/24' \*_
11. **&& nmcli connection up static**
12. After completing the tasks of this activity, return to the workstation machine as the student user.
