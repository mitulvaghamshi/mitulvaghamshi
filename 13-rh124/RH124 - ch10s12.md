## Summary

In this lesson, you learned about the different types of Linux user accounts and how to manage them. In Linux, the user account types are the superuser (the root user), system users, and regular users.\
Users and groups are used to secure and constrain access to files, processes, and other system resources. Each user has a primary group and might belong to one or more supplementary groups. User and group information is contained in the /etc/passwd, /etc/group, and /etc/shadow files.\
To manage user accounts from the command line, you usually use the system's superuser account. You can run commands as the superuser with the su and sudo commands.\
The superuser can configure a password management policy that requires a user to change their password on a periodic basis. The superuser can also lock access to a user account on a particular date, and can disable the shell program for a user account to prevent interactive logins.\
A system user or regular user can make some minor changes to their own user account, such as changing the password.
