# Guided Exercise: Manage Applications from Flatpak

List, search, install, remove, and get metadata information of applications by using Flatpak.\
**Outcomes**

- Use Flatpak commands to manage applications and runtimes.
- Install applications and review their information.
- Uninstall Flatpak applications and their dependencies.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start flatpak-application
```

**Instructions**

14. From the GNOME graphical desktop, launch the VSCodium and Obsidian applications to verify that they are installed correctly.
    1. Click the Red Hat logo in the upper-left corner of the screen to open the Activities Overview.
    2. In the search box, enter vscodium and click the VSCodium icon to open the application.
    3. Verify that the application starts correctly. Explore its interface, and close the application when you are finished.
    4. In the search box, enter obsidian and click the Obsidian icon to open the application.
    5. Click Quick Start to explore the application, and close the application when you are finished.

16. From the GNOME desktop, uninstall the Obsidian Flatpak with all its dependencies by using the GNOME Software graphical tool.
    1. From the GNOME graphical desktop environment, click the Red Hat logo in the upper-left corner and then select Software from the dashboard, or use the Show Applications button to open the application.
    2. Click the Installed tab. In the Apps section, find Obsidian, and click Uninstall. Click Uninstall to confirm.
    3. In the Add-ons section, find Freedesktop Platform. Click Uninstall, and click Uninstall again when asked for confirmation.
    4. Close the GNOME Software tool.
