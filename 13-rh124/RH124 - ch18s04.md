## Guided Exercise: Edit Network Configuration Files

Modify network configuration by editing configuration files.\
**Outcomes**

- Configure additional network addresses on each system.\
  As the student user on the workstation machine, run the following lab command to prepare your system for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start net-edit
```

**Instructions**\
Network interface names are determined by their bus type and the detection order of devices during boot. Your network interface names might vary according to the course platform and hardware in use.\
On your system, locate the network interface name (such as eth1, ens06, or enp0p2) that is associated with the 52:54:00:01:fa:1e Ethernet address. Use this interface name to replace the ens4 placeholder throughout this exercise if different.

3. As the root user, modify the Wired connection 1 profile to use the static IP address of 172.24.250.30/24, replacing the default DHCP configuration.

   4. Modify the Wired connection 1 profile to use the static IP address of 172.24.250.30/24.[root@servera ~]# *_nmcli con mod 'Wired connection 1' ipv4.method manual \*_
   5. **ipv4.addresses 172.24.250.30/24**
