## Summary

In this lesson, you learned about the tools that Red Hat Enterprise Linux provides to register systems, entitle them to product subscriptions, and receive software updates. RHEL tools help to track support contracts and subscription usage across systems.\
RHEL software is packaged in the RPM file format and distributed in repositories. You can install, upgrade, or remove software by using the rpm and dnf tools. The rpm command enables you to query the local RPM database and manage downloaded packages. The dnf utility is a powerful tool for managing software packages to install, update, remove, and query packages from configured repositories.\
You also learned that Red Hat Enterprise Linux provides the BaseOS and Application Stream (AppStream) repositories. BaseOS provides the core operating system content and AppStream provides a range of application packages and dependencies.
