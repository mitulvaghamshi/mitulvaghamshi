## Summary

In this lesson, you learned that the Bash shell is a command interpreter that helps users to specify Linux commands interactively.\
You learned some basic commands and shortcuts to help you to manage files, to complete file names, and to execute commands with fewer keystrokes.\
You also learned that you can use workspaces to organize the windows of multiple applications. The Activities Overview helps to organize windows and to start applications.\
You can use the graphical interface for many administrative tasks, and you can also disable the interface to preserve resources for running applications.
