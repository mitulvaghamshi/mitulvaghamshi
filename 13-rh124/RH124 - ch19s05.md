## Lab: Configure and Secure SSH

Protect SSH communication by managing host keys and by implementing key-based authentication for users.\
**Outcomes**

- Authenticate with SSH keys.
- Prevent users from directly logging in as the root user with SSH.
- Configure key-based authentication to prevent users from logging in by using passwords.\
  As the student user on the workstation machine, run the following lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start ssh-review
```
