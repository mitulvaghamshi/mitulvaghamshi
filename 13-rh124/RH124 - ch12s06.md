# Guided Exercise: Enable a DNF Software Repository

Configure a server to get packages from a remote DNF repository, and then update or install a package from that repository.\
**Outcomes**

- Configure a system to obtain software updates from a classroom server, and update the system to use the latest packages.\
  As the student user on the workstation machine, use the lab command to prepare your environment for this exercise, and to ensure that all required resources are available:

```
student@workstation:~$ lab start software-repo
```

**Instructions**\
In this guided exercise, you configure two software repositories on the servera machine. First you install a package from the custom repository at http://repo.example.com/rhel10.0/x86_64/rhcsa-practice/rht. Software maintainers then notify you about an available update for this package in the errata repository. You proceed to install the package from the errata repository: http://repo.example.com/rhel10.0/x86_64/rhcsa-practice/errata.\
