## Summary

In this lesson, you learned how SSH uses host keys to verify server identities to clients. By default, SSH clients maintain records of all hosts whose authenticity a user explicitly confirmed. These known host files can be configured both system-wide and on a per-user basis. You also explored how the ssh-keygen and ssh-keyscan commands are valuable tools for managing these host keys.\
SSH supports various methods for user authentication, including password-based and key-based authentication. For security and ease of use, users can generate a personal keypair by using the ssh-keygen command. To enable key-based access to a remote system, you can copy your public key to that system, to enable your corresponding private key to secure subsequent logins.\
